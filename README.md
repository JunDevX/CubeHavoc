> [!CAUTION]
> Проект в стадии прогрессивной разработки! Просьба при обнаружении багов / недочётов / вылетов / проблем создавать Issue с скриншотами и логами и полной информацией проблемы! Этим вы очень поможете!

# OpenSource
Проект пока что не предлагает открытый исходный код, предполагаемое открытие кода планируется на 500 или 1К звёзд!
Так же требуются **разработчики на C#** для улучшения работы кода!

# Системные характеристики
| Категория | Минимальные | Рекомендуемые |
| --- | --- | --- |
| Процессор | 2-ядерный CPU 1.5 ГГц (AMD A4 / Intel Celeron / Pentium) | 4-ядерный CPU 2.5 ГГц (Intel Core i3 / AMD Ryzen 3) |
| Видеокарта | Встроенная графика с поддержкой OpenGL 3.3 (Radeon R3 / Intel HD 4000) | Дискретная или современная встройка (NVIDIA GT 710 / GTX 750 / Radeon Vega 3) |
| Дрйвер | OpenGL 3.3 и выше | OpenGL 4.3 |
| ОЗУ | 2 ГБ | 4 ГБ |
| Интернет | Стабильное подключение от 5 Мбит/с (для локал сервера/Radmin) | Стабильный кабель / Ethernet от 10 Мбит/с |

# Возможные баги
Все баги которые могут произойти во время установки игры связаны именно с вашим устрйоством
| Категория | Решение |
| --- | --- |
| При заходе ошибка | Установите .NET 8 или выше |
| Не работает локальный сервер | Убедитесь что у вас с другом установлены последние версии игры |
| Ошибка при подключение к LAN серверу | Проверьте стабильность сети, 100% подключённый Radmin |
| Какие провайдером LAN сервера лучше пользоваться | Radmin самый отличный вариант, не рекомендуем использовать хамачи (Hamachi) так как под него не до конца настроены сервера LAN сервера и могут быть незаходы / вылеты / баги пинга |
| Другая проблема! | Идите в Discord форум или в [Issue](https://github.com/JunDevX/CubeHavoc/issues) |
