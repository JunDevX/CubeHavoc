Инструкция: Отправка ответов формы в Discord через Webhook

Так как веб-браузеры блокируют прямой доступ к ответам чужой iframe-формы из-за правил безопасности CORS, отправка данных из Google Формы в Discord Webhook выполняется за 1 минуту через встроенный сервис Google Apps Script:

  1. Откройте вашу Google Форму в режиме редактирования.
  2. В правом верхнем углу нажмите три точки ⋮ → Редактор скриптов (Apps Script).
  3. Вставьте код ниже (замените ваш Webhook URL) и сохраните:
function onFormSubmit(e) {
  var POST_URL = "https://discord.com/api/webhooks/СКРЫТ!!";
  var itemResponses = e.response.getItemResponses();
  var items = [];
  
  for (var i = 0; i < itemResponses.length; i++) {
    items.push({
      name: itemResponses[i].getItem().getTitle(),
      value: itemResponses[i].getResponse().toString() || "Не указано",
      inline: false
    });
  }

  var options = {
    method: "post",
    contentType: "application/json",
    payload: JSON.stringify({
      username: "CubeHavoc Bot",
      avatar_url: "https://i.imgur.com/4M34hi2.png",
      embeds: [{
        title: "🚀 Новая заявка на Бета-Тест CubeHavoc!",
        color: 16722507, // Красный цвет CubeHavoc
        fields: items,
        timestamp: new Date().toISOString()
      }]
    })
  };
  
  UrlFetchApp.fetch(POST_URL, options);
}
  1. Слева выберите иконку Триггеры (будильник) → Добавить триггер.
  2. Выберите функцию: onFormSubmit | Источник: Из формы | Тип события: При отправке формы.
  3. Нажмите Сохранить и подтвердите разрешения. Готово! Теперь ответы приходят прямо в Discord.
